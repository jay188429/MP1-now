# 프로젝트 개요 및 실습 안내 (README)

## 📌 미니 프로젝트 1: 시니어 자격증 접수 서비스 구축

본 프로젝트는 **중장년 및 시니어 대상 국가기술자격 접수 및 문의 응대 서비스**를 구현하는 미니 프로젝트입니다. 
발주처(두두자격지원센터 운영팀)의 요구사항에 따라, 수작업(워드 파일 및 전화 응대)으로 진행되던 기존 업무 프로세스를 디지털화하고 자동화하는 4개의 핵심 화면과 시스템을 구축합니다.

---

## 🎯 주요 구현 내용 (4개 화면 및 시스템)

| 구분 | 화면명 | 주요 역할 | 데이터 흐름 / 연동 방식 |
| :--- | :--- | :--- | :--- |
| **DB 쌍** | **1. 접수 화면** (`index.html`) | 자격증을 선택하고 신청자 정보(이름, 연락처 등)를 입력하여 접수 | 쓰기 $\rightarrow$ Supabase DB (`applications` 테이블) |
| **DB 쌍** | **3. 접수 어드민** (`admin/index.html`) | 접수된 신청 내역을 표 형태로 확인하고 오늘 접수 건수 등 현황 파악 | 읽기 $\leftarrow$ Supabase DB |
| **문서 쌍** | **2. FAQ 챗봇** (`app.py`) | 시니어 응시자의 질문에 대해 공식 문서 기반으로 정확한 답변 제공 | 읽기 $\leftarrow$ FAQ 문서 (`faq/faq.json` 등) |
| **문서 쌍** | **4. FAQ 어드민** (`faq/index.html`) | 접수 기간이나 규정 변경 시 개발자 도움 없이 직접 문서를 수정·관리 | 쓰기 $\rightarrow$ FAQ 문서 |

## 🛠️ 취급 자격증 8종 및 범위

- **한국산업인력공단 (큐넷)**: 한식조리기능사, 지게차운전기능사, 굴착기운전기능사, 전기기능사
- **한국산업인력공단 (전용 사이트)**: 손해평가사, 공인중개사
- **한국보건의료인국가시험원**: 요양보호사, 위생사

> ⚠️ **유의사항**: 본 프로젝트의 범위는 **필기 접수(또는 1차 접수)**에 한정됩니다. 실기 관련 문의 시 *"저희는 필기 접수만 도와드립니다"*로 안내하도록 설계되었습니다.

## 🚀 프로젝트 수행 흐름

### 1일차 (8/19, 수): 개발 및 구현
- **자격증 선정 (A)**: 8종 중 1종 선택
- **접수 화면 구현 (B)** 및 **Supabase DB 연동 (C)**
- **접수 어드민 구축 (D)**
- **FAQ 챗봇 백엔드 구현 (E)** 및 **FAQ 어드민 구현 (F)**

### 2일차 (8/20, 목): 튜닝, 통합 테스트 및 제출
- **용어 튜닝 (TUNING)**: "접수비", "포크레인", "요양사" 등 어르신들이 사용하는 구어체를 동의어 사전/문서에 반영하여 검색률 향상
- **챗봇 기준값(Threshold)** 설정: 모르는 질문에 대해 지어내지 않고 *"모르겠습니다"*라고 정확히 거절하도록 조정
- **통합 테스트 3종**: 통합 테스트, 회귀 테스트(`python app.py --test`), 유저 시나리오 점검
- **사용성 평가 및 최종 회고**: 수행일지 완성 후 PDF 변환 제출
